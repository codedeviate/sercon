# examples/data — sample-data corpus

This directory contains small, public-domain sample files used by the example
recipes under `examples/recipes/`.

Run `make sample-data` to regenerate the binary files from `generate.ts`.
Text/structured/tabular sources are authored by hand and committed directly.

## Manifest

| File | Format | Description |
|------|--------|-------------|
| `notes.txt` | Plain text | Short human-readable description of this directory |
| `server.log` | Space-delimited log | 22 HTTP access-log lines with a mix of 200/401/404/500 statuses |
| `config.toml` | TOML | Demo app configuration with `[server]` and `[logging]` sections |
| `config.json` | JSON | Same configuration as `config.toml` in JSON form |
| `catalog.xml` | XML | Product catalog with three `<product>` entries |
| `sales.csv` | CSV | 10 sales records: date, region, category, units, revenue |
| `regions.tsv` | TSV | 4 region records: region, manager, currency (tab-separated) |
| `products.xlsx` | XLSX | Two-sheet workbook: Products (4 rows, typed cells) + Categories |
| `legacy.slk` | SYLK | Legacy read-only SYLK export: 3-row inventory (sku, name, qty) |
| `small.png` | PNG | 64×64 pixel solid-colour image (~208 B) |
| `medium.png` | PNG | 400×300 pixel image (~1.1 KB) |
| `large.png` | PNG | 800×600 pixel image (~2.9 KB) |
| `photo.jpg` | JPEG | 400×300 pixel JPEG (~7.6 KB) |
| `barcode.png` | PNG | Code128 barcode encoding `SERCON-12345` |
| `tagged.jpg` | JPEG | 320×240 JPEG with EXIF Make=sercon, Model=sample |
| `sample.phpdump` | PHP serialize | PHP-serialized representation of a small object |
| `sample.perldump` | Perl Data::Dumper | Perl Data::Dumper representation of the same object |
| `generate.ts` | TypeScript | Generator script — run via `make sample-data` |

## Provenance

All sample data is original — generated by sercon (`make sample-data` runs
`generate.ts`) or authored by hand — and released into the public domain
(CC0 1.0). No third-party or licensed assets are included.
